# 비플·제로페이 점심지도

[원본 앱](https://seonn1010.github.io/SEONA2/bipl-lunch-map/)을 바탕으로 만든 별도 사본입니다. 원본 저장소와 사이트는 수정하지 않았습니다.

- L.L.M Academy(광주 서구 상무중앙로 44) 기준 직선거리600m.
- 원본54곳+추가44곳, 전체98곳. 음식점38·카페30·편의점/마트30.
- 2026-11-18 공식 제로페이 상호·주소 대조93곳. 건물번호가 없는 공식 지점명·도로명 대조5곳은 별도 표시.
- 식권 원본목록41곳은 과거 수록 근거이며 개인별 지원 식권의 결제 승인 여부를 확정하는 표시는 아닙니다.
- 실제 지원 식권 사용은 운영기관의 업종·매장·시간 설정에 따라 다릅니다.
- 원본 메뉴·가격·지도 링크를 보존했습니다. 확인되지 않은 신규 메뉴는 미확인으로 표시합니다.
- 키가 없으면 Leaflet+OpenStreetMap 지도를 표시합니다. 웹 주소에서 실행하세요. 로컬 파일 직접 열기는 지도 요청이 차단될 수 있습니다.
